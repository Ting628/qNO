# Benchmark Inputs

This directory now contains the supplied benchmark files:

```text
benchmark_inputs/
  MQT/
  nwq/
  qasm/
```

The collected data comprise 357 OpenQASM 2-style `.qasm` files, two `.qasm3` files, and one associated depth CSV. Windows `Zone.Identifier` attachment metadata have been removed because they are not research data.

If benchmark licences do not permit redistribution, include a download script and a manifest containing the upstream URL, release/commit, selected circuit names, preprocessing command, and SHA-256 checksum of each processed QASM file.

The manuscript reports 128 QASMBench, 116 MQTBench, and 112 NWQBench instances. The released manifest should account for every reported instance.

# QASMBench Results

`qasmbench_method_results.md` contains the per-circuit SWAP, depth, NLSP, runtime, and OT values for tket, SABRE, Duostra, and qNO. The qNO entries are synchronized with the `full_qno` rows used by the ablation analysis.

The status labels distinguish an actual `timeout` from a `read_error`; they are not numerical measurements.

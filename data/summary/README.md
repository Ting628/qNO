# Summary Data

- `ablation_delta_nlsp.csv`: per-case NLSP differences used in the ablation distribution.
- `ablation_group_means.csv`: grouped ablation means.
- `ablation_summary_rows.csv`: ablation summary table rows.
- `../results/qasmbench/qasmbench_method_results.md`: complete per-circuit method results used for the QASMBench comparison; the metric columns use the manuscript term `nlsp`.
- `qasmbench_aggregate_summary.json`: recomputed QASMBench normalized ratios, common-valid counts, and win counts.
- `qasm_full_qno_consistency.json`: automated check that all 128 qNO rows match the `full_qno` ablation records.
- `ablation_consistency.json`: automated check of grouped means, full-qNO baselines, and per-circuit ablation deltas.
- `qasm_2q_gate_counts.csv`: two-qubit-gate counts used in QASM analysis.
- `representative_qasm_2q_gate_counts.csv`: representative-circuit subset.
- `TVD.json`: candidate-level total-variation-distance analysis input/results supplied with the manuscript.

These are analysis summaries, not the complete raw experimental archive.
